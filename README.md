# Boat Records Support

Public support and privacy pages for the Boat Records iPhone app.

- Support: https://berkebasbay.github.io/boat-records-support/support.html
- Privacy Policy: https://berkebasbay.github.io/boat-records-support/privacy.html
- Support Issues: https://github.com/berkebasbay/boat-records-support/issues

Boat Records is a private, local-first iPhone app for keeping boat details, components, maintenance, documents, service history, checklists, search, and owner-ready exports organized on device.
